# SmartWater Optimizer

智能阶梯水费与节水优化器。基于本地阶梯水价与历史降水知识库，拆解家庭用水、预警城市供水紧张，并生成舒适度折损最小的节水行动组合。**运行时零外部网络依赖。**

## 快速开始

```bash
pip install -r requirements.txt
pytest -q
streamlit run main.py
```

Windows 用户也可直接双击 `WebClick.bat`。

## 界面功能

- **初始首頁**：參考簡報風格設計，柔和漸層卡片、文案置中、深色膠囊按鈕位於中心偏下；無任何閃動動效。
- **雙語切換**：右上角「繁中 / English」按鈕（單行顯示），所有文案、預警與行動清單同步切換，預設繁中。
- **三步驟控制台**：進入後左上角三個圓角按鈕 —— ① 地點與月份、② 生活類型、③ 計算結果，點擊各自切換頁面。
- **生活畫像**：內置 8 種畫像（獨居留學生、四人宿舍、三口之家、情侶雙人、獨居上班族、兩人合租、五口之家、住宿舍學生）。
- **地点预览**：内置 folium 交互式地图，切换城市后即时更新位置（底图需联网；水费与降水计算仍完全离线）。
- **月份降雨动画**：12 个月份卡片悬停弹出雨势窗口，按降水量自动播放小雨 / 中雨 / 大雨动画；点击卡片由 Streamlit 原生按钮在当前页面直接刷新切换月份，不弹出新页面、不整页重载。
- **账单周期**：界面统一以「每月」呈现估算（引擎仍按 4 个月账单周期精算后换算）。
- **淋浴参数**：按「每人每日分钟数」计算，并与家庭人数相乘。
- **节水措施上限**：每类措施的节水量不会超过该类别的实际用水量，避免推荐用户没有在用的项目。
- **高对比度**：所有文字/背景组合按 WCAG 标准控制在 7:1 以上。

## 项目结构

| 文件 | 职责 |
| --- | --- |
| `data/water_config.json` | 本地知识库：阶梯水价（香港/深圳/伦敦）、4 城市 12 个月降水与干旱阈值、8 个用户画像、10 条节水措施 |
| `water_engine.py` | 纯 Python 核心引擎，全部带类型注解与文档字符串，不依赖 Streamlit 或网络 |
| `main.py` | Streamlit 单页交互界面，只负责展示与调用引擎 |
| `test_water_engine.py` | pytest 单元测试套件 |

旧的雨水收集实现（屋顶水箱、集水面积、雨水收集、外网天气 API）已移入 `archive/`，不参与运行。

## 核心引擎 API

- `calculate_tiered_bill(total_m3, tariff_brackets)`：分段累进阶梯水费，返回总额、当前档位、距下一档临界点的 m³ 数与边际单价。
- `analyze_usage_breakdown(usage_params)`：4 个月周期总用水量、五类用水占比与头号"费水刺客"。
- `check_drought_status(city, month)`：少雨月份预警分级（normal / warning / critical）与动态收紧后的每日安全配额（升/人/日）。
- `generate_conservation_plan(current_usage, target_savings_hkd, drought_mode, tariff_key="hong_kong")`：穷举 0/1 背包搜索，在满足省钱目标的所有组合中选出舒适度折损总分最低的一组。

非法输入（负数时间、0 人家庭、未知城市、非法月份、未知阶梯地区等）会主动抛出 `ValueError` / `TypeError`。

## 阶梯水价示例（香港，4 个月账单周期）

| 用量 | 单价 |
| --- | --- |
| 首 12 m³ | 免费 |
| 13–43 m³ | HK$4.16 / m³ |
| 44–62 m³ | HK$6.45 / m³ |
| 超过 62 m³ | HK$9.05 / m³ |

临界点校验：12.0 → HK$0；12.1 → HK$0.416；43.0 → HK$128.96；62.5 → HK$256.035。

## 说明

深圳与伦敦的阶梯数据用于横向对比，降水数据为历史月均值，均为本地演示数据；实际账单请以当地水务机构公告为准。
